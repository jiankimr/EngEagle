설치 가이드

Chrome에 EngEagle 확장 프로그램을 설치하는 단계별 가이드입니다.

1

ZIP 파일 다운로드

위의 다운로드 버튼을 클릭하여 최신 버전의 ZIP 파일을 다운로드합니다.

EngEagle_v1.0.0_mv3.zip
2

안전한 위치에 폴더 만들기

바탕화면이나 문서 폴더처럼 실수로 삭제하지 않을 안전한 위치에 새 폴더를 만듭니다.

예: 바탕화면 → 우클릭 → 새 폴더 → "EngEagle" 등 원하는 이름으로 설정

이 폴더를 삭제하면 확장 프로그램이 동작하지 않습니다! 삭제하지 않을 위치를 선택하세요.

3

ZIP 파일 압축 해제

다운로드한 ZIP 파일을 2단계에서 만든 폴더 안에 압축 해제합니다.

  • ZIP 파일 우클릭 → 압축 풀기 또는 여기에 압축 풀기
  • 압축 해제 위치를 2단계에서 만든 폴더로 지정

💡 압축 해제 후 폴더 안에 manifest.json 파일이 있으면 성공입니다.

4

Chrome 확장 프로그램 페이지 열기

Chrome 주소창에 다음을 입력하고 Enter를 누릅니다:

chrome://extensions/

또는 Chrome 메뉴(⋮) → 도구 더보기 → 확장 프로그램을 선택합니다.

5

개발자 모드 활성화

확장 프로그램 페이지 우측 상단의 "개발자 모드" 토글을 켭니다.

💡 토글을 켜면 상단에 새로운 버튼들이 나타납니다.

6

"압축해제된 확장 프로그램을 로드합니다" 클릭

개발자 모드를 켜면 나타나는 "압축해제된 확장 프로그램을 로드합니다" 버튼을 클릭합니다.

폴더 선택 창이 열리면, 2-3단계에서 만들어서 압축 해제한 폴더를 선택합니다.

manifest.json 파일이 있는 폴더를 선택해야 합니다! ZIP 파일이 아닌 압축 해제된 폴더를 선택하세요.

EngEagle 아이콘이 도구 모음에 나타나면 설치 완료! 🎉

7

DeepL API 설정 (선택, 무료)

로컬 사전에 없는 단어도 번역하려면 DeepL API를 설정하세요.

DeepL API Free는 무료입니다! 한 달에 최대 500,000자까지 번역할 수 있습니다.

  • 여기서 무료 API 키 발급받기 →
  • 확장 프로그램 아이콘 우클릭 → 옵션 선택
  • DeepL API 설정 섹션에서 API 키 입력
  • 연결 테스트 버튼으로 확인 후 저장

💡 API 키는 브라우저에 저장되며, 수정 전까지 계속 유지됩니다.

자주 묻는 질문

확장 프로그램이 동작하지 않아요

페이지를 새로고침하거나, chrome://extensions에서 확장 프로그램을 비활성화했다가 다시 활성화해 보세요.

단어가 사전에 없다고 나와요

DeepL API를 설정하면 모든 영어 단어를 번역할 수 있습니다. 무료 API 키를 발급받고 옵션 페이지에서 설정하세요.

DeepL API는 무료인가요?

네, 무료입니다! DeepL API Free는 한 달에 최대 500,000자까지 무료로 번역할 수 있습니다.

단어장 데이터는 어디에 저장되나요?

모든 데이터는 브라우저의 IndexedDB에 로컬 저장됩니다. 외부 서버로 전송되지 않습니다.

다른 PC로 단어장을 옮길 수 있나요?

옵션 페이지에서 JSON 또는 CSV로 내보내기 후, 다른 PC에서 가져오기 하면 됩니다.

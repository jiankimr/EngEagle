📋 EngEagle 설치 가이드

Chrome에 EngEagle 확장 프로그램을 설치하는 단계별 가이드입니다.

1

ZIP 파일 다운로드

다운로드 페이지에서 최신 버전의 ZIP 파일을 다운로드합니다.

EngEagle_v1.0.0_mv3.zip
2

ZIP 파일 압축 해제

다운로드한 ZIP 파일을 원하는 위치에 압축 해제합니다.

압축 해제한 폴더를 삭제하면 확장 프로그램이 동작하지 않습니다. 안전한 위치에 보관하세요.

3

Chrome 확장 프로그램 페이지 열기

Chrome 주소창에 다음을 입력하고 Enter를 누릅니다:

chrome://extensions

또는 Chrome 메뉴 → 도구 더보기 → 확장 프로그램을 선택합니다.

4

개발자 모드 활성화

확장 프로그램 페이지 우측 상단의 "개발자 모드" 토글을 켭니다.

5

확장 프로그램 로드

"압축해제된 확장 프로그램을 로드합니다" 버튼을 클릭합니다.

파일 선택 창에서 압축 해제한 EngEagle 폴더를 선택합니다.

EngEagle 아이콘이 도구 모음에 나타나면 설치 완료!

6

DeepL API 설정 (선택)

더 많은 단어 번역을 위해 DeepL API를 설정하세요.

  • DeepL 무료 API 키 발급받기
  • 확장 프로그램 옵션 페이지 열기
  • DeepL API 설정 섹션에 API 키 입력
  • 연결 테스트 후 저장
7

사용 시작

이제 EngEagle을 사용할 준비가 되었습니다!

  • 영문 웹페이지에서 단어를 더블클릭하세요
  • 번역 팝업이 표시됩니다
  • 단어가 자동으로 단어장에 저장됩니다
  • 옵션 페이지에서 단어장을 관리하세요

파일 무결성 검증 (선택)

다운로드한 파일이 변조되지 않았는지 확인하려면 SHA256 체크섬을 검증하세요.

Windows (PowerShell)

Get-FileHash EngEagle_v1.0.0_mv3.zip -Algorithm SHA256

macOS / Linux

sha256sum EngEagle_v1.0.0_mv3.zip

자주 묻는 질문

확장 프로그램이 동작하지 않아요

페이지를 새로고침하거나, chrome://extensions에서 확장 프로그램을 비활성화했다가 다시 활성화해 보세요.

단어가 사전에 없다고 나와요

DeepL API를 설정하면 모든 영어 단어를 번역할 수 있습니다. 옵션 페이지에서 API 키를 설정하세요.

단어장 데이터는 어디에 저장되나요?

모든 데이터는 브라우저의 IndexedDB에 로컬 저장됩니다. 외부 서버로 전송되지 않습니다.

다른 PC로 단어장을 옮길 수 있나요?

옵션 페이지에서 JSON 또는 CSV로 내보내기 후, 다른 PC에서 가져오기 하면 됩니다.
